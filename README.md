# Pharmacist Income & Business Tax Planner — Interactive Prototype

ต้นแบบเว็บแอปภาษาไทยที่จำลอง 5 เส้นทาง: รายได้ของฉัน, ภาษีเงินเดือนเบื้องต้น, เศรษฐศาสตร์ร้านยา, เปรียบเทียบบุคคลธรรมดากับบริษัท และรายการที่ควรตรวจต่อ

## วิธีทดลอง

1. หน้า **รายได้ของฉัน**: กดรายการเพื่อแก้ไข หรือกดเพิ่มรายได้ แล้วเปิด “ดูที่มาของตัวเลข”
2. หน้า **ภาษี**: เห็นตัวอย่างเฉพาะรายได้เงินเดือน รายได้ชนิดอื่นติดป้ายว่าต้องตรวจประเภทก่อนรวมคำนวณ
3. หน้า **ร้านยา**: เปลี่ยนยอดขาย ต้นทุนสินค้า และค่าใช้จ่าย แล้วสังเกตกำไรก่อนภาษี
4. หน้า **เปรียบเทียบ**: ดูกรณีบุคคลธรรมดาหักเหมาและบริษัท SME; เปิดรายละเอียดสูตร เปลี่ยนต้นทุนบัญชี ค่าลดหย่อน ทุนชำระแล้ว และสัดส่วนเก็บกำไร
5. หน้า **สิ่งที่ควรตรวจต่อ**: รายการสำหรับหารือกับนักบัญชี

ตัวอย่างเริ่มต้นมาจาก Workshop: ยอดขาย 3,960,000 บาท, ค่าใช้จ่ายร้านจริงรวม 1,800,000 บาท, ค่าบัญชีบริษัท 50,000 บาท, ค่าลดหย่อนตามโจทย์ 210,000 บาท. เมื่อจ่ายกำไรหลัง CIT ทั้งหมดเป็นปันผล กรณีตัวอย่างได้ PIT แบบเหมา 208,500 บาท, CIT SME 271,500 บาท และภาษีหัก ณ ที่จ่ายปันผล 183,850 บาท

## ขอบเขตสำคัญ

- Rule set มีสถานะ `illustrative` สำหรับ Workshop เท่านั้น **ไม่ใช่กฎที่อนุมัติให้ใช้ยื่นภาษีปี 2569**
- ผลภาษีส่วนบุคคลหน้า “ภาษี” รวมเฉพาะเงินเดือนที่ยืนยันแล้ว ค่าเวร บรรยาย หรือ consulting อาจจัดประเภทต่างกัน จึงไม่แสดงยอด PIT รวมที่อาจทำให้เข้าใจผิด
- ตารางบริษัทแสดงกรณีจ่ายปันผลทั้งหมด; slider ด้านล่างเป็นสถานการณ์เก็บกำไรบางส่วน ภาษีหัก ณ ที่จ่ายปันผลอาจไม่ใช่ภาระสุดท้ายของผู้รับ
- VAT แสดงธงเตือนเมื่อยอดขายเกินเกณฑ์ตัวอย่าง แต่ยังไม่คำนวณ VAT รายหมวดสินค้า
- ไม่มีบัญชีผู้ใช้ การบันทึกถาวร การยื่นแบบ หรือการส่งข้อมูลออกไปยังผู้ให้บริการภาษี ข้อมูลที่กรอกอยู่ในสถานะของหน้าเว็บขณะเปิดใช้งาน

## พัฒนาและรัน

ใช้ Node.js, `npm ci`, แล้ว `npm run dev -- --host 0.0.0.0 --port 4173 --strictPort`; ตรวจด้วย `npm run check:runtime` และ `npm run build`. คอมโพเนนต์แอปอยู่ใน `src/Prototype.tsx`, สไตล์ใน `src/prototype.css`, สูตรตัวอย่างแยกใน `src/taxEngine.ts`. ไฟล์ runtime ของ mobile template คงเดิม
